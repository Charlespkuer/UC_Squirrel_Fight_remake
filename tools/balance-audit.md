# 数值核对与版本取舍（2026-09-23）

本轮完整阅读 `references/new/攻略.md`、`references/new/reference.md`，并核对原版 `GameDict.js`、`player.js`、原客户端技能面板及 Mission。攻略正文包含多个时期文章，甚至同一文件内有“技能最高10级”和后来的“真五技能”；不能把所有片段当作同一版本。优先采用明确的原始数据与可互相印证的规则。玩家现有存档的属性、资源、武技和已通关记录不回溯扣减。

## 已落实

- **经验**：逐项采用 reference 的1–50级升级经验，13级1270、20级2220、40级5450、50级7280；前50次升级总计161410。原实现从13级开始偏离。
- **出生与成长**：普通新建鼠生命30–50，`力量+敏捷+速度+生命/5=22`，初始无武技。普通升级固定5生命，另3点随机分至力/敏/速/生命，每个生命属性点换5生命。出生分配概率未留存，采用简单等概率分配；此概率不是原服务器还原。
- **武技**：固定等级2、3、4、6、8、10、12、14、16、18、20；23至50每3级；56、62、68。武器16/17、技能23/24到50级才进入随机池，师父驾到只能经师徒关系获得。武技位置上限跟随这些等级，拜师赠予技能不占随机领悟位置。
- **属性书**：53、59、65级仅发1本属性书，不发本级随机成长/武技。使用必须明确分配8个整数点到力/敏/速，未分配或参数非法均不消耗。
- **被动基数**：风驰电掣初始2速、每级+1，身强体壮初始5血、每级+8；十级11速、77生命与攻略后段数值互证。原词典 `propertyAdd` 表达每级增量，不能直接乘级数忽略初始值。
- **升级限制**：费用、卷轴、玩家等级与成功率读取原表：当前等级1至14的成功率为100/100/100/70/60/40/25/15/10/100/8/5/4/3%。通常费用50，武器10升11费用100。原技能面板明确技能10满级、装死和师父不能升级，所以普通技能停10；旧档11–15等级保留，不删除。
- **转生**：50级及以后拒绝；此前重置等级/基础属性/武技，保留物品与装备并卸装，不再发初次升5级50金奖励。普通新建无武技，Debug仍可显式指定开局武器。
- **药剂**：原价格与10/30体力恢复、20回合等数值保留；PPT问答明确百分比药剂退一取整，改为floor，仍有最低5/10的加成。
- **每日限购**：依用户明确要求，普通商店每种每天5个，稀有每天1个。当前原表实际出售的稀有是转生果13、天使果实47；永久属性16–19、属性书37、红包38、恶魔果实48及礼包/宝箱/魔法袋也归稀有类别，但原表不出售的物品仍不开放购买。限购按本地日期保存，批量超额整体拒绝，失败购买不计数，礼包获得或背包数量不占购买额。Debug免费商店免价格但不绕日限。金杯商店的周限使用独立字段，没有被日限重置。
- **NPC与掉落**：保留原表关卡HP，5/6星熊猫分别1419/1703/2555与2797/3357/5035，与攻略吻合。修正原表#127四星仙鹤误写stageId=4的问题。关卡每次击败对手都结算碎片，1–6个；主类别按螳螂/仙鹤/熊猫选择白/绿/蓝，星数越高越可能越一级（★3–4越1级、★5–6越2级，蓝封顶），整轮总经验仍按原Mission的19+3×(stageId−1)，金币25。
- **装备词条**：PPT明确白绿无附加属性、蓝装1条最高2星、紫装2条最高3星；新合成与AI装备遵守，旧装备不删改。相同词条只取最高仍保持。
- **离线AI**：基础属性成长预算与玩家一致，固定领悟位置及装备/升级等级限制一致，已有随机名称、等级抖动保留；实际应用AI装备基础属性和词条，并保留独立裸属性供战斗技能使用。
- **师徒费用与日贡**：收徒挑战改为10金松果，不扣体力；已有师父则打候选的真实师父快照，没有师父则打候选本人，不额外生成师父。状态层保存进行中的报名，重复点击/重入不二次收费，播放错误或刷新未完战斗退费一次，旧回调与换档回调不发徒弟/奖励。出师20金，重复确认不重复扣款。
- **昨日活动账目**：日贡改为普通主动挑战、被挑战、关卡经验的10%，体力报名经验竞技经验的5%，两类合计后取整。战斗拾取、抽奖、英雄帖报名经验竞技均不计入。每位离线徒弟每天最多8条有限模拟活动，按徒弟名字/入门日/活动日生成稳定结果，保存最近7天账目，UI可展开查看每项经验来源与计入比例。只领取昨日账目、每天一次；只生成入门时间之后的活动，因此新收徒当天不能领昨日全额，深夜入门也不会补算白天。领取不减少徒弟经验。旧档没有入门日期的，从迁移日开始计算，已有当日领取标记保留。

## 保留的版本差异与不可确认部分

- reference与PPT的仙鹤生命表243/292/438等与原客户端表188/226/339等不同；前者还和本版一星熊猫完全重合。未证明对应同版本，不用跨时期表覆盖原客户端。
- 攻略列出的武器十级伤害与原表也有差异，继续用原字典基本伤害和增量。升级成功率文字多列了一个100%，但逐级原表与其预期费用可对应，采用原表。
- 后期“真技能”、橙黑圣雄凤凰装备与宝石属于不同更新期。本轮未用只有真五端点、缺逐级数据的描述去臆造真技能成长。
- 51级以上经验没有可靠完整表，沿用原项目离线外推，每级比50级多250；代码与本文明确标识为补足，不宣称原版。
- 关卡碎片精确概率及少量跨颜色掉落率无服务器数据。保留现有随星级变化的离线触发率，只校正确定的结算时点（每次击败对手）、主类别及1–6数量，并按攻略的“3星小概率出高一级颜色、6星几率提高”设置 ★3–4 越1级、★5–6 越2级。暂不臆造白绿蓝之间其他方向的小概率转换。
- 天使果实原说明可能抽中已拥有武技而失败，当前离线实现从可获得且未拥有池中抽取；无可靠抽签概率，未改为未经证实的失败率。
- 初始资源、每日礼包、普通战斗经验/金松果、红包金额等没有这次资料中的充分一致证据，保留当前离线实现。徒弟每天具体活动量与时间没有历史服务器记录，使用明确标注的有限离线模拟：9:10/12:30/18:40主动挑战、15:10被挑战，11级以上19:20可有经验竞技，10级以上20:10有关卡，21:00拾取、部分日期22:00抽奖；后两项只展示账目、不贡献日贡。模拟概率与数量不是原版事实。现有收徒胜利20经验保留，未把它当作已经查实的原版奖励。

## 接口与验证

`State.shopLimit(id)` 返回5、1或无效物品0。`State.purchaseStatus(id)` 返回 `{date, limit, bought, remaining, buyable}`，读状态时自动日切。`State.buyProp` 在状态层原子校验余额、数量和限额。`State.useProp(37,{power,agility,speed})` 分配属性书；升级返回项 `attributeBook:true` 供UI显示。

`State.apprenticeDailyStatus(徒弟对象)` 返回昨日活动账目、经验、是否可领和是否已领；`apprenticeDailyExp` 也接受徒弟对象，不再用等级套公式。`apprenticeTribute(activities)` 只按来源和报名方式计提。`beginRecruitChallenge` / `finishRecruitChallenge` / `cancelRecruitChallenge` 管理费用与战斗token。

回归脚本：`tools/test-balance.cjs` 14项、`tools/test-state.cjs` 23项、`tools/test-stages.cjs` 13项。`tools/test-extras.cjs` 30项涵盖竞技/天梯/师徒，新增日贡精确比例、排除来源、午夜/深夜入门、旧档迁移、账目持久、防重复领取与收徒错误退款/换档保护。战斗掉落独立 `tools/test-battle-drops.cjs` 9项验证三次调度、约两秒过期、点击/跳过幂等、取消不补、换档不发、升级与掉落汇总。

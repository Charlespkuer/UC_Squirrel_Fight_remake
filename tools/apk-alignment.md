### D. 本轮追加的玩法改动（按反馈）

| D1 | 天使果实种子 | **武技已满时也能合成**（原来直接禁用按钮）。详情只保留提示：「已满，果实仍可合成，等有空位时再使用」 |
| D2 | **天梯碎片 → 转化丸** | 依据 `references/new/微信图片_20260924010916_259_2.jpg`：天梯战里飘出的「请点击」改用专属掉落表（`BattleDrops.poolFor('rank')`），点到的就是**天梯碎片**（新道具 id 51，原数据 51~100 为空号，只在 `gamedata.js` 补行，`GameDict.js` 仍与 APK 逐字节一致），并有机会掉恶魔果实种子。10 个天梯碎片 + 50 金松果在兑换页随机合成一个**力量／敏捷／速度转化丸**（转化丸 10/11/12 是原版道具，原本没有任何获取途径）。图标由白色碎片改色加「?」生成，属派生素材 |
| D3 | 难度下调 | 新增 `GData.STAGE_DIFFICULTY`：关卡 NPC 血量 ×0.85、力量 ×0.88、敏捷/速度 ×0.96（原表 `STAGE_NPC_HP` 原样保留，只在取值时打折）。螳螂大招触发血线 35% → **20%**、每击 0.55 → 0.36 倍、低血爆发 1.5 → 1.3 倍；仙鹤开场重击 1.6 → 1.35 倍。实测（14 级玩家、每组 40 场）：1 星螳螂大侠挨打均值 34.3 → 25.8，3 星螳螂大侠 NPC 胜率 43% → 3%，大招触发血线 35% → 16~20% |
| D4 | **挑战经验改为按等级差** | 旧公式 `10 + 对手等级×1.2` 随对手等级绝对值上涨，高等级时随机挑战反而压过经验竞技场。改为 `基准 = 27 + 自己等级×1.2`，再乘 `1 + (对手等级−自己等级)×0.14`（下限 0.3、上限 2.2）。参数挑成 **20 级刚好是反超点**：20 级同级一场 51 点，单位体力效率 5.1 首次超过竞技场的 150/30 = 5.0，之后一路拉开（60 级 9.9）。同时按需求**不设硬上限**，但 1~60 级在实际会遇到的等级差（−1~+3）下单场经验最高 141，仍低于竞技场冠军 150。每级所需场次单调递增：0.7 → 21.8 → 41.4 → 59.5 → 83.7 → 98.8 |
| D5 | **关卡奖励换回原值，改调碎片掉率** | 上一轮把关卡经验/金松果翻倍，本轮按用户要求**换回原表数值**（`STAGE_REWARD_MULT = STAGE_GOLD_MULT = 1`，即逐场 3/4/18、整轮 25、通关金松果 25）。真正改的是碎片：掉率从 `0.42+星级×0.03`（45%~60%）提到 `0.55+星级×0.04`（**59%~79%**），数量从 1~6 收窄到 **2~5**（均值仍是 3.5，标准差 1.71 → 1.12），越级概率不变（0.72）。集中在 `GData.STAGE_FRAGMENT` |
| D6 | **升级礼包丰富化** | 原来只有属性成长 + 随机武技。现在每级随机给 1~2 个消耗品（技能/武器卷轴、大小体力药剂、力量/敏捷/速度丸、经验丸），逢 5 级与属性书等级（53/59/65）再给大礼包：挑战书 ×2 + 技能卷轴 ×3 + 武器卷轴 ×3 + 大体力药剂 ×2，并额外抽一个稀有项（超级经验丸/丹药）。同类会合并计数；奖励面板与关卡战果都会多出一排金色礼包卡 |
| D7 | **药剂批量使用 + 体力硬上限 999** | 药剂不再要求「体力未满」才能用：可以把体力顶到自然上限之上，最高 **999**（`State.energyHardCap()`）。超过 `maxEnergy` 的部分只是**不再自然回复**，存档往返也不会被清掉（`normalizeSave` 与 `syncVipEnergyCap` 都改成只按硬上限收口）。道具详情用一个「使用数量」**滑动条**选个数（主按钮实时显示 `使用 ×N`，下面预告用完后的体力），主界面体力条在超上限时加金色高亮与说明文案 |

## 六、桌面版实测（Tauri，Windows 11 / 2026-09-25）

用户要求「尝试使用 Tauri，点开启动器时不是用浏览器打开的游戏，而是一个单独的界面」，所以这一轮不只写代码，还真的在本机把它编译出来跑了一遍。

| 项目 | 实测结果 |
| --- | --- |
| 工具链 | `rustup-init.exe --profile minimal` 装出 **rustc / cargo 1.98.1**（`x86_64-pc-windows-msvc`）；复用机器上已有的 MSVC 生成工具 2026 与 WebView2 运行时 153；`npm install` 只装 2 个包（`@tauri-apps/cli`） |
| 前端暂存 | `node tools/build-tauri-web.cjs` → `src-tauri/web` **1479 个文件 / 54.9 MB** |
| 图标 | `npx tauri icon app-icon.png` → `icons/`（含 `icon.ico` 65 KB、`icon.icns` 768 KB、各尺寸 PNG 与 Windows Store 图） |
| 编译 | `cargo build --release` **2 分 24 秒** → `target/release/ssdz-classic.exe` **48.89 MB**（前端整包嵌进二进制）+ `ssdz_classic_lib.dll` 0.12 MB；`target/` 约 1.5 GB，cargo registry 342 MB |
| 运行 | 原生窗口标题 **「松鼠大战 · 怀旧复刻版」**，尺寸 1216×760（本机 150% 缩放 → 物理 2217×1405），窗口里就是游戏本体：标题画面 → 点进背包页都正常（截图核对过） |
| 桌面版存档 | 启动后自动写出 **`%APPDATA%\com.ssdz.classic\save\progress.json`（711 字节）**，证明 `js/tauri-bridge.js` 成功把存档通道换成了 Rust 命令（`save_meta/save_read/save_write/save_path`），浏览器版仍走 `/__save` |

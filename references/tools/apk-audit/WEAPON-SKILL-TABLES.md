# 原 APK 的武器 / 技能数值表，与本地文件的逐项对比

> **结论**：原 APK 里**有完整的两张机制表**——`weaponsMap`（17 件武器，含每级伤害与特效参数）
> 和 `skillsMap`（20 个技能，含类型与说明），外加 `upgradeMap`（武技升级成功率/费用/门槛）。
> 本地的 `js/orig/GameDict.js` 与 APK 内的同名文件 **逐字节完全相同**
> （都是 90,759 字符，`sha256:fe608242cf4b8a63`）——**数据零差异**。
> 真正的差异只有两类：①词典只给「文本说明 + 几个参数」，**战斗中怎么用是复刻时自己定的**；
> ②**真·武器（11~15 级）的 `harmAdd1` 语义要在词典之外推断**，是本项目的一处解释性选择。

## 二、本地怎么用这两张表（与词典的对应关系）

| 词典字段 | 本地实现 | 位置 |
| --- | --- | --- |
| `harm` + `harmAdd` | 1~10 级：`伤害 = harm ± 0 + harmAdd × (level−1)` | `js/state.js` `weaponInst()` |
| `harmAdd1`（5 个值） | **11~15 级按「逐级增量」累加**：`+ harmAdd×9 + Σ harmAdd1[0..level−11]` | 同上 |
| `remark1`（真武器额外效果） | 超过 10 级后额外效果**再加一份固定值**（西瓜刀 +5% 连击、流星锤 +3% 三投、激光剑 +3% 暴击、狼牙棒 +6 持续伤害、板砖 +3% 眩晕、忍者镖 +2% 吸血、沉默之斧 +4% 沉默） | `js/sim.js` `weaponEffect(w, base, perLevel, perTrueLevel)` |
| `propertyAdd` | 只用于说明；实际被动加成写在 `GData.passiveBonus()` | `js/gamedata.js` |
| `upgradeMap` | 直接驱动升级成功率/费用/卷轴/等级门槛 | `js/state.js` `upgradeInfo()/doUpgrade()` |

## 四、差异清单（真正需要注意的地方）

1. **`harmAdd1` 的语义是推断的**：词典只给了 5 个数字，没说是「每级增量」还是「当级总量」。
   本项目按**逐级增量**处理，于是 15 级方天画戟 = 15-25 + 12×9 + (20+30+40+50+60) = **333-343**；
   若按「当级总量」则只有 35-45。攻略只给了十级表（与公式吻合），**真武器 11~15 级没有可对照的数字**，
   所以这一条是本项目一处**未被证实的选择**（代码集中在 `weaponInst()` 一处，想改很容易）。
2. **被动技能 3 / 4 的初始值**：词典 remark 只说「每级 +1 点」「每级 +8 点」，字面上 1 级应是 1 / 8；
   本项目给的是 **风驰电掣 1 级 +2、身强体壮 1 级 +5，之后每级 +1 / +8**（`passiveBonus`，已被测试钉住
   「10 级分别 11 速 / 77 血」）。这是一处**基于攻略示例与手感的选择**，与词典文字不完全一致。
3. **百分比口径**：木剑 / 移形换位 / 流星锤的闪避按**相对天生闪避**提升（PPT 问答的 25%×1.3=32.5% 示例），
   不是直接加百分点；三者叠加按相加、上限 55%（无原服公式可证）。
4. **原服公式无法从 APK 恢复**：伤害/命中/闪避/反击/防御触发这些**函数**在服务端（见
   `APK-CONTENTS.md` 第三节），客户端只播放 `combatLog`。所以 sim.js 里这些是**离线设计**：
   命中基准 `6 + 26×敏捷比`、暴击基准 5%、龟甲触发 35%、绝对防御触发 30%、小宇宙只算裸属性、
   师父驾到血线 35% 与 35% 概率、武器出手权重 45/80 等——都是本项目取舍，不是原版数值。
5. **未按词典实现的两处小偏差**（有意）：
   - 技能 9「暴击」的发动率用的是 `2 × 等级`（词典「每级 +2%」若按 1 级起算应是 2%），项目按 2%/级累计；
   - 技能 10「皮糙肉厚」按 `5% + 1%/级`，技能 7 龟甲按 `20% + 5%/级` 并限制最多 80%。
6. **词典里的 `remark1` 明确是「真武器额外效果」**，本项目只在等级 > 10 时叠加（按 `weaponEffect` 的第 4 个参数），
   普通 10 级不再额外加成——这一点与攻略「普通十级效果封顶、真武器再额外加」一致。

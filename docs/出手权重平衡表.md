> **本文件由 `node tools/gen-weight-sheet.cjs` 自动生成**，所有数字都从 [`js/sim.js`](js/sim.js) 现算，
> 改完 `RULES` / `repeatRateOf` 之后重新生成一次即可，不会手抄走样。
>
> 模型说明见 [战斗系统数值手册.md](战斗系统数值手册.md) §3；本文只放数值与调参入口。

> **当前参数**：`repeatWeapon = 30`、`repeatSkill = 20`、
> `repeatSpecialFirst = 15`（17/12 用过 1 次后）、`repeatSpecialAgain = 5`（17/12 用过 2 次及以后）、
> `commonAttackWeight = 30`、`npcSkillChance = 30`、`LAST_PENALTY = 0.3`、`UNUSED_WEIGHT = 100`。

## 1. 模型一句话

三个池子放进**同一次加权抽取**：

```
武器权重 = (本场用过 ? repeatWeapon(30) : 100) × (上一招是它 ? 0.3 : 1)
技能权重 = (本场用过 ? 该技能的二次档位 : 100) × (上一招是它 ? 0.3 : 1) × (1 + skillBoost)
徒手权重 = RULES.commonAttackWeight(30)                  ← 常数

P(某一项) = 它的权重 / (Σ武器权重 + Σ技能权重 + 徒手权重)
```

- 「没用过 100」是**同一个池子里的相对基准**，不是百分比。
- 只有**当前可用**的候选参与求和：缴械时武器池清空、沉默/冷却/本回合已用/满血不放（来点松果）的技能不进池。
- 技能的二档只分两类：**来点松果(17) / 野球拳(12)** 两段式，**其余技能**一律 `repeatSkill`。

## 7. 不走权重抽签的分支（读表前必须知道的例外）

| 分支 | 行为 | 位置 |
| --- | --- | --- |
| 固定循环敌人（挑战塔松鼠 boss、题面 boss） | 完全按 `pattern` 数组出招，**不看权重** | `sim.js` 的 `att.pattern` 分支 |
| C33 抽中小宇宙（`mods.cosmosFirst`） | 开战第一招**强制**放技能 14 | `forceCosmos` |
| 方天画戟（武器 1）已蓄力（`pendingWeapon`） | 下一次出手**强制**用武器 | `sim.js` |
| 缴械 / 沉默 | 对应池子直接清空（只影响权重分母，不影响规则） | `canWeapon` / `canSkill` |
| 三侠等纯 NPC（`npcType`） | 独立固定档位：`npcSkillChance = 30`（技能 / 普攻） | `pickNpcKind` |
| 玩家式 AI（挑战 / 竞技 / 天梯 / 师徒对手） | **与玩家同一套权重**（对称） | `playerLikeAction` |

## 8. 目前**无法**通过数据表调整的东西（需要改代码）

1. **单件武器的权重差异**：所有武器完全对称，没有「某把武器更少见」的字段。
   ⇒ 副作用：**低等级 / 低伤害的旧武器与神装的出现频率完全一样**（只要还在背包里）。
   想区分的话，最小改动是在 `weaponWeight()` 里加一张 `WEAPON_WEIGHT[id]` 表（默认 1），
   或者按 `w.level` / 基础伤害给一个「越强越常出」的系数。
2. **徒手权重随持有数量变化**：`commonAttackWeight` 是常数（30），
   「高持有玩家少普攻」靠的是**工具总权重随件数增长**的边际效应（见 §3.1 曲线），不是显式函数。
3. **每场战斗内的权重漂移**：只有「用过 / 刚用过」两档状态，没有「随回合数递减」之类的函数。
4. **技能 14 / 17 的重复档位**：它们每场 1 次、用后出池，所以表中「用 2 次及以后」的行只是理论值。

## 9. 复算方式（改完自己验）

```js
// 照 tools/test-combat-rules.cjs 的 game() 加载 gamedata.js + sim.js 之后：
const S = c.Sim;
const att = { usedWeapons: {}, usedSkills: {}, skillUseCount: {}, lastWeaponId: null, lastSkillId: null };
S.kindWeights(att, [{ id: 6 }], [12]);   // → { weapon, skill, common, total, weaponShare, skillShare, commonShare }
S.actionWeights.weapon(att, 6);          // → 单件武器权重（没用过 = 100）
S.actionWeights.skill(att, 12);          // → 单件技能权重
S.repeatRateOf(12, 2);                   // → 用过 2 次之后的档位
S.rules;                                 // → 全部 RULES 常量
```

| 想改什么 | 位置 |
| --- | --- |
| 徒手权重（全局） | `RULES.commonAttackWeight`（30） |
| 武器二次权重 | `RULES.repeatWeapon`（30） |
| 其余技能的二次权重 | `RULES.repeatSkill`（20） |
| 来点松果 / 野球拳的二次权重 | `RULES.repeatSpecialFirst`（15）/ `repeatSpecialAgain`（5） |
| 受这份曲线影响的技能 id | `js/sim.js` `repeatRateOf()` 里判定 `id !== 12 && id !== 17` 的那一行 |
| 「没用过」的基准权重 | `js/sim.js` `UNUSED_WEIGHT`（100） |
| 「上一招」惩罚 | `js/sim.js` `LAST_PENALTY`（0.3） |
| C33 的技能加成 | `js/tower-data.js` C33 的 `pickSkillPct`（0.60）与 `tower.js` 的 `DEFENSE_PICK_BOOST/JUE_DUI_PICK_BOOST` |
| 纯 NPC 档位 | `RULES.npcSkillChance`（30） |

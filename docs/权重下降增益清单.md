## 0. 一句话口径

塔池里影响「会不会抽到某条增益」的一共四个旋钮（前两个是**个体级**，后两个是**档位级**）：

| 旋钮 | 数据字段 | 规律 | 什么时候用 |
| --- | --- | --- | --- |
| 静态权重 | `mods.shopWeight` | 恒定倍率（不随份数变） | 想让某条整体更稀有时 |
| 每份衰减 | `mods.repeatWeight` | 第 n 份 → `r^(n-1)`（n ≥ 2 才生效） | 「再出现概率 ×r」的旧口径 |
| 除以份数 | `mods.weightDivBy` + `mods.weightDivOffset` | `1 / (n + offset)`，`n+offset ≤ 1` 时不降权 | 「越拿越难再出现」的现口径 |
| 档位降权 | `legendWeightFactor` | 传奇档整体 ×`0.88^已拥有传奇条数` ×（全部可重复传奇到手 ? 0.35 : 1） | 传奇档整体缩水 |
| 保底权重 | `mods.pityWeight` | 只影响传奇保底那一格的**档内**加权（0 = 不进保底池） | 保底给谁 |

另外注意：`weightDivBy` 的降权**还会按比例缩小整个稀有度档的预算**（`dynamicTierWeights`），
所以一条增益降权时，同档其它增益也会一起变稀有 —— 不是「把它的概率分给同档别人」。

## 5. 复算方式

```js
const run = Tower._debugRun('endless');
run.slotFreeIds = new Array(3).fill('x');        // C37：3 个附魔
Tower.buffWeightOf(run, 'C37');                  // → 1/3
run.limited = [{ id: 'C49', stacks: 3, uses: 1000, on: true }];
run.fragileGot = { C49: 3 };                      // 含碎掉的
Tower.buffWeightOf(run, 'C49');                  // → 1/3
Tower.dynamicTierWeightsOf(run, TD.endlessPool);  // 档位预算（个体降权会按比例缩整档）
```

# 无尽塔·勇者模式特殊机制总结

> 适用范围：无尽塔大厅「剧本」选择 **勇者剧本** 后进入的对局（状态层 `run.ruleset === 'hero'`）。
> 显示名统一为「勇者」；代码内部仍保留 `hero` / `TowerHero` / `hero-*` 等标识，属于实现命名，不在界面上出现。
> 本文只整理**当前代码实际行为**，不把历史更新记录里的旧名称当作现状。

---

## 一、模式定位与入口

| 项目 | 当前规则 |
|---|---|
| 入口 | 无尽塔开局页右下角「剧本」选择：**默认剧本 / 勇者剧本**；选勇者剧本后，「开始攀登」先进入勇者准备页。 |
| 对局槽位 | 勇者模式与常规无尽塔共用同一个 `endless.run` 槽位，同一时间只能进行一局；不能同时开常规局与勇者局。 |
| 记录 | 分数、周最高、最深层的**勇者记录独立**（`heroBest` / `heroWeekBest` / `heroBestLayer`），与常规无尽记录分开记账。 |
| 货币与结算 | 不另立货币或门票：仍使用本局的试炼币、铸币、抽奖卷与结算流程；失败/放弃/结算规则与无尽塔一致。 |
| 剧本选择持久化 | 剧本选择本身不写入存档；重新进入开局页默认回到「默认剧本」（准备页草稿在同一页面生命周期内保留）。 |

---

## 二、开局构建（勇者准备页）

### 2.1 初始武技

- 从**全部可学习**的武器与技能中选 **恰好 3 个**，开局等级固定为 **5 级**。
- 同一武器 / 技能不能重复选择。
- 可学习范围使用 `GData.canLearn(kind, id, 90)`：因此包含全部武器与绝大多数技能；**技能 13「师父驾到」不在可学习池**。
- 被动技能 1~4（力 / 敏 / 速 / 生命）也在可选范围内；选择后按技能 5 级的被动值加到勇者面板（见 2.2）。

### 2.2 初始四维与重分配

| 项目 | 数值 |
|---|---|
| 初始力量 / 敏捷 / 速度 | 65 / 65 / 65 |
| 初始生命上限 | 800 |
| 力敏速总点数 | 195（三项合计固定） |
| 20% 占比下限 | 55（生命按 5 点折 1 点属性，总预算 275） |
| 单项上限 | 85 |
| 可分配池上限 | 30（三项都压到 55 时） |

- 生命固定 800，**不参与**力/敏/速的重新分配。
- 力/敏/速可在准备页用上下键调整：从一项扣 1 点进入公共池，再加到另一项；不能低于 55，不能超过 85。
- 三项合计必须始终为 195；有未分配点时不能开始挑战。
- 选择被动技能后，面板显示的是「初始值 + 被动加成」；被动等级后续提升时，最终战斗面板也会重新计算。
  - 5 级被动示例：技能 1 力量 +10、技能 2 敏捷 +10、技能 3 速度 +5、技能 4 生命上限 +40。
- 当前**没有一键重置**按钮，只能逐点上下调整。

### 2.3 外观

- 四个部位：头部 / 拳套 / 衣服 / 鞋子。
- 可选范围为装备字典中的**全部 280 件外观**（原始 288 件，合并了黑狂战 46/67、黑怒战 47/68 两组 id 不同但外观 / 属性一致的重复黑装），包括普通、稀有、史诗、橙装与黑装；不要求账号已拥有；每一套装备的四件都可以选。
- 现代界面直接复用「状态 → 更换装备」的纸娃娃 + 每页 6 件外观页：同样四部位槽位、蓝勾、翻页与装备名，但**不显示任何属性、套装收益、宝石或出售入口**；点一下穿上，再点一下脱下。经典界面继续用 7218 的纯外观换装页。
- 外观件**只改变立绘/战斗造型，属性、词条、宝石、套装效果全部为 0**。
- 外观不写入账号装备栏；只保存在本局 `run.hero.appearance` 中，爬塔中和跨百层后仍可查看、更换。

### 2.4 准备页草稿

- 已点亮的 3 个武技、四维分配、外观都保存在**界面内存草稿**里。
- 关闭准备页回到开局页再进来，草稿仍在；刷新页面 / 重开游戏后草稿丢失，回到默认初始状态。
- 点「开始挑战」成功后草稿清空；开局失败则保留草稿。

## 三、战斗体与账号隔离

勇者进入战斗时由 `TowerHero.fighter()` 构造一个**独立战斗体**，不读取账号的角色面板。

| 项目 | 是否继承账号 |
|---|---|
| 等级 | 否。战斗体固定 `level: 90`，仅用于战斗/界面口径，不代表账号等级。 |
| 力量 / 敏捷 / 速度 / 生命 | 否。使用勇者自己的初始值 + 本局被动加成 + 本局增益。 |
| 武器 / 技能 | 否。只使用 `run.hero.weapons` / `run.hero.skills`。 |
| 账号装备、套装收益 | 否。外观装备只进 `gears` 作为造型，且 `effects` 为空。 |
| 账号被动技能 | 否。只有勇者自己学到的被动技能 1~4 生效。 |
| 药丸 / 消耗品 | 否。塔战本身 `useProps: false`，勇者也没有账号道具入口。 |
| 师父 / 幻兽 | 否。`masterLevel: 0`、`pets: []`。 |
| 账号存档 | 勇者战斗不写账号武技、装备、药剂或幻兽；只写 `run.hero` 与本局状态。 |

- 战斗开场血量按勇者当前生命上限满血进入；后续按无尽塔的绝对血量/层间回复规则结算。
- 敌人的数值曲线与常规无尽塔**相同**，没有因为勇者基础面板较低而单独下调（见第八节的风险与优化）。

## 四、局内武技成长

### 4.1 每场胜利

每次战斗胜利（`TowerHero.grow`）：

1. `wins + 1`；精英胜利同时 `eliteWins + 1`；巡逻魔王胜利同时 `patrolWins + 1`。
2. 从当前已掌握、等级未满 15、且不是技能 6「装死」的武技中**随机选 1 个**，进行一次普通升级尝试。
3. **每一层最后一场战斗胜利**额外有概率随机学会一个尚未掌握的武技，新学技能为 **5 级**（与开局、HS04 统一）；第一层最后一战固定 **100%**，其余层按当前已掌握武技总数反比衰减。
4. 如果所有可升级武技都已满级，本场不产生升级；`wins` 仍然增加。
5. 最近 20 条成长文本写入 `run.hero.log`，战斗结束后用飘字提示。

### 4.1.1 最后一战领悟概率

概率按**当前已掌握武技总数**（武器 + 技能，含 HS04 的免上限武技）计算：

```text
pct(n) = 8000 / (9n + 60) - 10/3
```

精确拟合用户给定三点，并向下衰减：

| 已掌握武技数 | 领悟概率 |
|---:|---:|
| 4 | 80% |
| 5 | 72.9% |
| 6 | 66.8% |
| 8 | 57.3% |
| 10 | 50% |
| 12 | 44.3% |
| 15 | 37.7% |
| 20 | 30% |
| 24 | 25.7% |
| 30 | 20.9% |
| 40 | 15.7% |
| 50 | 12.4% |
| 100 | 5% |

- 第一层最后一战固定 100%，不受上表影响；
- 非最后一战不判定新武技；
- 达到普通 24 项上限后不再判定（HS04 仍可特殊突破）；
- 同一场最后一战可以同时发生「已有武技升级」与「新武技领悟」。

### 4.2 普通升级概率与保底

| 当前等级 → 目标 | 基础成功率 | 失败保底 |
|---|---|---|
| 1 → 2 | 100% | — |
| 2 → 3 | 100% | — |
| 3 → 4 | 100% | — |
| 4 → 5 | 70% | 普通级失败 +2%/次 |
| 5 → 6 | 60% | 普通级失败 +2%/次 |
| 6 → 7 | 40% | 普通级失败 +2%/次 |
| 7 → 8 | 25% | 普通级失败 +2%/次 |
| 8 → 9 | 15% | 普通级失败 +2%/次 |
| 9 → 10 | 10% | 普通级失败 +2%/次 |
| 10 → 11 | 100% | 真级固定，无保底 |
| 11 → 12 | 8% | 真级固定，无保底 |
| 12 → 13 | 5% | 真级固定，无保底 |
| 13 → 14 | 4% | 真级固定，无保底 |
| 14 → 15 | 3% | 真级固定，无保底 |

- 普通级（< 10 级）连续失败每次 +2 个百分点，成功或进入真级后清除失败计数。
- 真级（11~15 级，界面显示「真1~真5」）使用固定概率，不再累计保底。
- 最高为 15 级（真5）；技能 6「装死」不可升级。

### 4.3 武技数量上限与特殊学习

- 普通学习上限 = `GData.wsLimit(90)` = **24 个**（武器 + 技能合计，只数**占上限**的武技）。
- 达到 24 后，普通战斗与普通学习不再增加新武技；`HS04 禁书残页` 属于特殊传承，可以突破普通上限。
- **HS04 学会的武技即使还没到 24 项也不占计数**（记在 `hero.uncapped` 的 ref 列表里）；普通学习仍按未豁免的武技数判定 24 上限。
- `HS02 遗忘与新生` 不改变总数：**自选**遗忘一个已学武技，再**自选**学习一个尚未掌握的武技，新武技**继承被遗忘武技的等级**；被遗忘的是 HS04 豁免件时，新武技继续豁免 24 上限。
- 每层最后一战学习、授业事件「学习陌生招式」、HS04 都是 **5 级**新技能；HS02 学习等级看被遗忘的那一项。
- **真化白值乘数（勇者专属）**：武技达到真1~真4时，其白值 ×1.5；达到真5时 ×2；普通等级 ×1。武器白值为 `harmLo/harmHi`，技能作用于伤害/治疗/增益等白值，被动 1~5 的属性加成同样吃乘数；普通无尽塔不受影响。

### 4.4 非战斗期「铸币修炼」

- 在爬塔中的**勇者详情页**（现代状态页 / 经典 7218 状态页）点「铸币修炼」：花 **1 枚铸币**，从勇者已掌握、未满 15 级且可升级的武技中自选一个，**必定随机提升 3~5 个小级**，封顶真5。
- 只改 `run.hero`，不写账号；技能 6「装死」、技能 13 以及已满 15 级的武技不在候选内。
- 战斗令牌存在（`run.attempt`）时拒绝；商店 / 结算 / 际遇等非战斗阶段可以使用。
- 铸币来自勇者际遇、无尽塔结算等既有来源；不足 1 枚时按钮提示但不会扣费。

### 4.5 重试与回滚

- 铸币重试使用战前快照 `retrySnap`：会回滚本场战斗前的**勇者成长**（wins / eliteWins / patrolWins / log / 武技等级 / 学习结果 / HB01 层数）与血量，不会重复结算成长。
- 外观修改不属于战斗快照，不会被重试回滚。

## 五、勇者专属货品

以下货品只在勇者对局中出现；默认无尽塔的池子会通过 `hero` 标签过滤掉它们。

| 编号 | 名称 | 品质 | 效果 | 获取/说明 |
|---|---|---|---|---|
| HS01 | 勇者修炼札 | 稀有 | 随机选一个未满级武技，连续进行 **3 次普通升级尝试**，遵循原成功率与失败保底。 | 勇者试炼/铸币商店；可重复。 |
| HS02 | 遗忘与新生 | 史诗 | **自选**遗忘一个已学武技，再**自选**学习一个未掌握的武技；新武技**继承被遗忘武技的等级**，总数不变。 | 勇者商店；可重复；购买前先选目标。 |
| HS03 | 大师传承 | 史诗 | **自选**一个未满级武技，直接升到 **真5（15级）**。 | 勇者商店；可重复；购买前先选目标。 |
| HS04 | 禁书残页 | 传奇 | 随机学会一个未掌握的 **5 级**武技；该武技**不占普通 24 项上限**（未满 24 时也不计数）。传奇动态权重按 **0.5^n** 递减（n = 本局已获得次数）。 | 勇者商店；可重复。 |
| HB01 | 勇者之剑 | 传奇 | 不占永久栏位，跨百层保留；魔王·镜完成面板复制与自身增益后，其力量 / 生命上限按破镜层数降低。**每击败一次巡逻魔王成长 1 层，最多 10 层**；1 层为 −20% / −35%，每多 1 层再各 −2%。 | 首次巡逻胜利后的 `forge` 际遇；同名唯一；详见第七节。 |

- HS01 / HS03 的候选池只包含「未满 15 级、且不是技能 6 / 13」的已有武技；没有合法目标时这件货品会从池子中消失。
- HS02 / HS04 在「所有武技都已掌握」时也会从池子中消失；HS04 的豁免件不计入 24 上限，因此可以继续扩充。
- HS02 / HS03 是**购买前自选**：界面先弹出选择层，选完才真正扣费/发货；取消选择不消耗。
- 这些货品是**即时类**：购买后立刻生效，不进入永久/限次栏位。

## 六、勇者际遇（事件）

### 6.1 通用规则

- 事件由 `Tower.heroEventInfo()` / `resolveHeroEvent()` 管理；**独立于剧情模式开关**——关掉 TowerPlot 的文字剧情不会跳过勇者际遇。
- 每个事件在**本局内只触发一次**（记录在 `run.hero.events`）；未完成事件前不能开始下一场战斗。
- 打开无尽塔主界面时，事件优先于普通塔页显示；解决后回到塔页，再继续原有的剧情/商店/选牌流程。
- 事件按固定优先级检查；一次只展示一个未完成事件。
- 选择记录随存档与战前快照保存/回滚。
- **界面与剧情模式共用**：`TowerPlot.eventHtml()` 用 `.tower-story` 的整屏版式（塔身 + 楷体文字 + 奶油底）渲染，只在文字下方加选择键，不再另做「事件卡」。
- **开局没有 departure / 60 试炼币**：勇者从塔门醒来直接进入第一场战斗。

### 6.2 勇者剧情文本

- `TowerPlot.SCRIPTS` 的 43 段（开场、商人、巡视、层间主线、整百层、四雄）都有一份同 id 的 `TowerPlot.HERO_SCRIPTS` 勇者文本；`storyScript()` 在当前对局 `ruleset === 'hero'` 时自动取用，`once` / 触发条件沿用默认表，勇者的「只播一次」记账用 `hero:<id>` 前缀，与默认局分开。
- 勇者文本围绕「断锋、镜塔、仍认得自己的勇者」重写；开局、进商店、遇到巡视、失败缴藏品、王庭终章都换成勇者视角，不再复用默认登塔者的旁白。
- 勇者际遇只走 `TowerPlot.eventHtml()` 的 `.tower-story` 模板；`tower-ui` 的事件卡兜底已删除。
- 回归在 `tools/test-tower-hero.cjs`（43 段全覆盖 + 剧情模板 + 默认/勇者文本分流）；默认模式剧情仍由 `test-mint-shop` / `test-env-buff` 盯触发条件。

### 6.3 事件表

| 事件 id | 触发条件 | 选项与效果 |
|---|---|---|
| `forge` | `patrolWins >= 1`（**首次巡逻胜利**；巡逻魔王是路上最难的一类遭遇） | 「拔出断锋」：获得 HB01；或「收下巡逻缴获」：获得 **180 试炼币**。 |
| `mentor` | **第一次自然触发铸币商店时替换该次商店** | 「复盘旧招」：随机升级 **4 次**武技（每次从可升级武技中随机）；或「记下陌生一招」：随机学会一个 **5 级**武技（受普通 24 项上限限制）。 |
| `campfire` | `wins >= 25` | 「借火重整气息」：接下来 **10 次战斗**，每回合开始回复 **5% 生命上限**；或「带走火中的铸币」：获得 **1 枚铸币**。 |
| `reflection` | `run.layer >= 41` | 只有「记住破绽，暂避其锋」：获得 **180 试炼币**。 |
| `returning-sword` | `run.layer >= 60` 且尚未持有 HB01 | 「这一次，握住它」：获得 HB01（破镜层数按已击败巡逻魔王补算）；或「绕过断锋」：获得 **1 枚铸币**。 |
| `last-lesson` | `run.layer >= 80` | 「把这一式练到极处」：**自选一个武技直接升到真5满级**；或「为最后的补给留余地」：获得 **300 试炼币**。 |
| `cycle-<轮次>` | `run.layer > 100` | 只有「以新一轮旅途为名」：接下来 **10 次战斗**，每回合开始回复 **10% 生命上限**。 |

补充：

- 事件按上表顺序检查；同一时刻只显示第一个未完成事件。
- `forge` / `mentor` / `campfire` / `reflection` / `returning-sword` / `last-lesson` 一局只触发一次；`cycle-<轮次>` 每个 100 层循环一次。
- `forge` 的触发条件从「首次精英胜利」提高到「**首次巡逻胜利**」：巡逻魔王会复制勇者面板，遇到与打赢都明显更难；`returning-sword` 是 60 层后仍未持剑的第二次机会。
- `ascension-<层>`「破晓铸痕」事件已移除；整百层胜利后不再额外弹事件/给铸币。
- `mentor` 的「复盘旧招」与 `last-lesson` 的「升满」在全部武技满级时仍可能没有可结算目标；事件会被标记完成，这是当前实现的保留边界（见第十节）。
- 授业 / 登顶训练的「随机未满级武技」不包含技能 6（装死）与技能 13。
- 勇者际遇的剧情文本已整体重写为「断锋照影 / 阶前的盲眼师 / 倒燃的营火 / 巡镜者 / 断锋归鞘 / 钟声之前 / 镜外的新雪」，与普通剧情模式的文风区分开。

## 七、勇者之剑（HB01）

- 获取：`forge`（**首次巡逻胜利**）或 `returning-sword`（60 层后、仍未持剑）二选一；两次都选择放弃后，本局不再出现寻剑事件。
- 占位：带 `story` 标签，**不占永久增益位**，不参与永久位替换流程。
- 保留：跨 100 层「照影之境」重置时，`clearMirrorBuild` 会保留 HB01 **以及它的破镜层数**；它不会被封存进照影之境。
- 唯一：`unique`；同一局最多一把。`maxStacks: 10`，破镜层数最多 10。
- 成长：**每击败一次巡逻魔王 +1 层**（路上巡视与整百层觐见魔王都算）；未持剑时先记 `hero.patrolWins`，之后拿到剑时按累计次数补层。1 层时力量 −20%、生命上限 −35%；每多 1 层再各 −2%，10 层封顶（−38% / −53%）。
- 克制对象：只对 `patrol` 类敌人生效，包括路上「巡视」的魔王与整百层「觐见魔王」的魔王本体；不影响两名近卫、普通 boss 或三侠。
- 生效顺序：在魔王完成「复制玩家面板 → 接收玩家上交的增益 → 整百层魔王额外命数」之后，再乘力量 / 生命上限的破镜系数，并标记 `heroCounter = '勇者之剑·破镜 ×N'`。因此它克制的是复制后的最终面板。
- 战斗界面会显示「勇者之剑·破镜 ×N」的机制提示。

## 八、与无尽塔主循环的交互

勇者模式**不是**独立塔，而是无尽塔的一个剧本；下列规则与常规无尽塔共用：

- 层结构：三侠位、随机 boss、x10 狂战、整百层觐见魔王三连战。
- 环境词缀、商店、场间三选一、20 层后每 10 层献祭、50 层黑卡、100 层循环、照影之境、隐藏成就与分数。
- 三侠大招的「本层削弱」：
  - 螳螂「重伤」：生命上限 −3%~6%/次，本层累计最多 −15%；
  - 仙鹤「战吼」：随机一项属性 −5%~10%，本层最多 3 次；
  - 熊猫「压制」：随机锁一把武器或一个技能，本层最多 2 个。
  - 锁武技时使用**勇者自己的**武器/技能列表，因此会实际影响本局可选招式；进入新层清空。
- 环境、商店、献祭等按轮内层号在每 100 层重置规则，与常规无尽塔一致。

### 8.1 照影之境与勇者

进入第 101 / 201 / 301… 层时：

- 快照取样使用 `TowerHero.fighter(run.hero)` 的勇者面板，而不是账号面板。
- `clearMirrorBuild` 清空普通永久/限次增益与大部分本局成长字段，但保留：
  - 照影之境 C63；
  - 勇者之剑 HB01；
  - `run.hero`（初始四维、武技与等级、外观、事件记录、wins/eliteWins/patrolWins、log）。
- 勇者的事件已读记录**跨百层保留**，所以 forge/mentor 等不会在 101 层重播；`cycle-<轮次>` 每轮一次。
- 照影之境封存的静态属性会在新一层继续叠加到勇者面板上；勇者的基础四维/被动仍作为白值，不会被清空。
- 外观与武技在跨百层后继续有效；旧普通增益则按照影规则封存。

### 8.2 重试与铸币

- 战败后可用 1 枚铸币回滚本场；回滚包含勇者成长与战前快照，避免「重试刷成长」。
- 铸币本身来自勇者际遇、无尽塔结算等既有来源，没有单独的勇者铸币。

## 十、当前实现观察与风险

1. **记录未展示**：`heroBest` / `heroWeekBest` / `heroBestLayer` 只写不读，玩家在开局页仍看到常规记录，容易误以为勇者成绩没被记录。
2. **难度口径未单独调**：勇者初始 65/65/65/800，而敌人沿用常规无尽曲线；勇者没有账号装备/等级/幻兽补偿，前期体感可能明显更硬。`forge` 已提高到首次巡逻胜利，前期拿到剑的时点更晚。
3. **准备页草稿只在内存**：刷新页面会丢失三个武技、四维分配和外观选择，且没有「重置分配」按钮。
4. **事件奖励可能空耗**：`mentor` 的 4 次随机升级 / `last-lesson` 的自选升满在全部武技满级时没有目标；`learn` 在 24 项上限时也会失败，但事件仍会被消费。
5. **寻剑选择不可逆**：`forge` / `returning-sword` 放弃剑后本局不再出现勇者之剑；缺少二次确认。
6. **HS01 仍是随机目标**：HS03、HS02、铸币修炼都已可自选；HS01 保留随机 3 次以维持随机性。
7. **外观与账号的边界**：外观可选全部 280 件（含未拥有黑装；重复黑装已合并），界面上已写「0 加成」；仍建议补一句「不校验账号拥有」。
8. **事件与剧情优先级**：勇者际遇优先于 TowerPlot 剧情；同一节点两者都待播时会先打断剧情播事件。
9. **勇者际遇文本与普通剧情风格区分**：事件已改用剧情模式整屏界面并重写文本，但事件仍不写入 `storySeen`，刷新页面后的重播判定只依赖 `run.hero.events`。

## 十一、优化建议

### P0：先修可感知的问题

1. **在大厅展示勇者记录**（未做）
2. **准备页「重置分配 / 重置草稿」**（未做）
3. **事件奖励兜底**（未做；满级 / 24 项满时仍可能空耗）
4. **寻剑二次确认**（未做）

### P1：提升构筑可控性

5. **定向训练**（已完成）
   - HS03、HS02、铸币修炼都已自选目标；HS01 保留随机 3 次。
   - 状态页仍未显示每个武技的当前成功率与保底层数，可作为后续增强。
6. **准备页显示「不可升级」标记**（未做）
7. **四维分配推荐 / 预设**（未做）

### P2：难度与长期节奏

8. **勇者专属难度系数（数据驱动）**
   - 先统计勇者 1~20 层、21~50 层、51~100 层的通关率/平均剩余血量，再决定是否给勇者前若干层一个敌人系数折扣或额外起始资源。
   - 不建议直接改常规无尽曲线；应像 `FOE_HERO_*` 一样做成勇者专用乘区，便于回滚。
9. **100 层后的勇者节奏**
   - 101 层后事件只剩 `cycle-<轮次>` 回血，勇者成长也已接近上限；建议每轮给一个「新轮次际遇」或允许一次武技重选，让跨轮仍有构筑决策。
10. **记录与结算分栏**
    - 结算页把「常规最佳 / 勇者最佳」并列；勇者战报可单独保留最近一局，避免常规与勇者的 `lastSummary` 互相覆盖。

### P3：文案与维护性

11. 把 `hero` / `TowerHero` / `hero-*` 保留为内部标识，但所有**玩家可见文本**统一为「勇者」；后续新增文案直接以「勇者」为准，避免再次混入旧称。
12. 将勇者初始值、成长概率、事件奖励集中到一处配置（目前初始值在 `TowerHero.CONFIG`，事件奖励分散在 `tower.js`），便于后续平衡时不跨文件查找。

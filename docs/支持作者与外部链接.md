# 自愿支持作者（爱发电）与「打开外部链接」

> 目标：游戏里放一个**自愿**的支持入口 —— 系统页最上方一个按钮，外加升到 30 级时的一次性提示。
> 链接：<https://ifdian.net/a/Charlespkuer>（爱发电）。
> 支持**不换取任何游戏内好处**：没有内购、没有广告、不解锁内容、不影响平衡（与 [LICENSE](../LICENSE) 一致）。
> 回归：`需求137`（`tools/test-fixes-round.cjs`）。

---

## 1. 界面放在哪

| 入口 | 位置 | 行为 |
|---|---|---|
| **系统页按钮** | `系统` 页**最上方**的 `.support-panel`（`classic-ui.js` 的 `supportPanelHtml()`，拼在 `grid` 之前） | 打开 `支持作者` 弹窗 → 「用浏览器打开爱发电」 |
| **30 级一次性提示** | 升到 30 级时自动弹一次（`State.gainExp` 埋点 → `classic-ui.js` 的 `maybeSupportPrompt()`） | 同一个弹窗，文案换成「你已经 30 级了…」 |

关键时序（这条是刻意的）：提示**不在升级的那一刻插队**，而是挂在
`promptLevelUpChoices()` 的尾巴上 —— 也就是「武技三选一 → 自由属性点 → 都处理完了」之后
才轮到它；正在弹别的窗（`.classic-modal-overlay` 存在）时也让路。
`State.supportPromptTake()` 是原子的：**取到就立刻写进存档**（`supportPromptShown = true`），
所以只会出现一次；调试面板「重弹『支持作者』提示」可把它恢复成待提示（`State.supportPromptReset()`）。

文案与链接都在一处：`js/main.js` 的 `Main.SUPPORT = { url, label }`。
**换渠道只改这一行**，界面不用动。

## 2. 「用浏览器打开」怎么实现的（三种运行环境三条路）

`Main.openExternal(url)`（`js/main.js` 的【MN9】）按环境依次尝试，全部失败返回 `false`，
界面随即弹「复制链接」兜底（`showSupportFallback()` + `copyText()`）：

| 运行环境 | 判定 | 走哪条路 |
|---|---|---|
| **轻壳模式**（双击 exe，窗口打开 `http://127.0.0.1:<端口>/`） | **有 `window.__TAURI__`** 且 `location` 是自己人（127.0.0.1/localhost + 端口） | `fetch('/__open?url=…')` —— 由**内置迷你服务器**（`src-tauri/src/lib.rs` 的 `handle_request`）调用系统打开器 |
| **安装版 / 安卓**（页面来自 `tauri.localhost` / `tauri://`） | 有 `window.__TAURI__` 且不是自己的服务器 | 先试 `window.__TAURI__.opener.openUrl`（装了 opener 插件时），否则 `invoke('open_external', { url })` |
| **便携包 / 网页版 / file://** | 没有 `window.__TAURI__` | `window.open(url, '_blank')`（**同步**调用，保住「用户点击」手势，否则会被弹窗拦截）；开完手动断开 `opener` |

为什么轻壳模式必须绕开 IPC：Tauri 2 的 capability 默认**不给「远端来源」**（页面来自
`http://127.0.0.1:端口` 就算远端）任何权限，连自定义命令都会被 ACL 拒绝 ——
`js/tauri-bridge.js` 开头的注释里记着这个坑（所以那边存档改走 `/__save` HTTP 接口）。
外部链接同理：轻壳模式走 `/__open`，安装版/安卓走 IPC。

Rust 侧两处（都在 `src-tauri/src/lib.rs`）：

```
fn spawn_opener(url: &str) -> std::io::Result<()>   // Windows: cmd /C start；macOS: open；Linux: xdg-open；Android: am start -a android.intent.action.VIEW
#[tauri::command] fn open_external(url: String)     // 安装版 / 安卓
fn open_api(query, out)                             // 轻壳的 /__open（普通 HTTP，不受 capability 限制）
```

安全：`spawn_opener` 只接受 `http(s)://`、只允许可见 ASCII、并禁掉 `" ' & | ^ < > \`` 这些
shell 元字符（避免把 URL 交给 shell 时被拼接执行）。

> ⚠️ **需要重编一次 exe / apk**：这一版改了 `src-tauri/src/lib.rs`（加了 `/__open` 路由与
> `open_external` 命令），所以：
> - **网页版 / 便携包 / 正在跑的开发服务器**：立刻生效（只改了 js/css），按钮直接可用；
> - **旧 exe / 旧 apk**：JS 会依次尝试三条路，全都不通时会弹「复制链接」——
>   功能不致命，但要真的「一键跳浏览器」得重编一次。
> 本机没有 Rust 工具链，**这两段 Rust 代码没有经过编译验证**：重编时若报错，
> 把 `lib.rs` 里 `spawn_opener` / `open_external` / `open_api` 三块与 `generate_handler!` 里多出的
> `open_external` 删掉即可回到原状（JS 侧会自动退到「复制链接」）。

## 3. 安卓上的注意点

`spawn_opener` 在安卓上走 `am start -a android.intent.action.VIEW -d <url>`。
部分机型的 SELinux 策略会拦住应用 fork/exec 系统命令 —— 那种情况下 `spawn` 返回错误，
前端会退回「复制链接」弹窗（可用，但不够顺）。

要 100% 稳，就把安卓那条路换成官方插件（改动很小，但要重新加依赖）：

```toml
# src-tauri/Cargo.toml [dependencies]
tauri-plugin-opener = "2"
```
```rust
// src-tauri/src/lib.rs run()
tauri::Builder::default()
    .plugin(tauri_plugin_opener::init())
```
```json
// src-tauri/capabilities/default.json（新建）
{ "$schema": "../gen/schemas/desktop-schema.json", "identifier": "default",
  "windows": ["main"], "permissions": ["core:default", "opener:default"] }
```
JS 侧**不用改**：`openExternal` 已经优先用 `window.__TAURI__.opener.openUrl`。

## 4. 常见维护问题

| 问题 | 结论 |
|---|---|
| 换收款渠道要改游戏吗？ | 不用。改 `Main.SUPPORT.url` 一行即可；更省事的做法是让它指向你自己控制的静态页（例如 `https://<你的用户名>.github.io/<仓库>/support.html`），以后页面里随便换平台，游戏一行都不用动 |
| 要不要定期更新？ | 静态方案**不需要**。链接是固定的；只有「直接写死第三方平台且平台关站/改域名」才需要发新版 |
| 支持要给回报吗？ | **不要**。一旦用支持换内容（皮肤 / 属性 / 解锁）性质就变成内购，既违背 [LICENSE](../LICENSE) 的非商业条款，也更容易踩到原作权利边界 |
| 想让所有人（不只 30 级以上）看到入口？ | 系统页的按钮一直都在；这里只是额外给 30 级玩家一次提示 |
| 想关掉 30 级提示？ | 把 `js/state.js` 里 `SUPPORT_PROMPT_LEVEL` 调高到 70（或删掉 `maybeSupportPrompt()` 那一行调用）即可 |

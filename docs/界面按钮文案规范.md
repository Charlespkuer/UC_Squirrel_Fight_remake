# 界面按钮文案规范

> 用户 2026-10 口径：**按钮里的汉字尽量 2~3 个，最多 4 个；不要带括号。**
> 这份规范只约束**动作按钮的可见标签**；物品名、角色名、道具效果、弹窗正文不在此列。
> 规范的可执行版本是 `node tools/test-button-labels.cjs`（CI 会跑）。

## 1. 硬性规则

| 规则 | 说明 |
|---|---|
| 汉字 2~3 个 | 这是默认目标。例如「导入」「导出」「保存」「返回」「确定」「取消」「挑战」。 |
| 最多 4 个 | 4 个汉字是上限，不是目标；能用 2~3 个说清就不要写 4 个。 |
| 不带括号 | 中文 `（）`、英文 `()`、方括号、书名号都不进按钮标签。费用、等级、数量改放正文、标题或徽章。 |
| 不带省略号 | 不用「选择文件…」；按钮本身已经表示要打开后续界面。 |
| 状态值外置 | 「分辨率：自动」「全面屏：开」「调试所得（3）」这类写法拆成「分辨率」+ 右侧小徽章 / 绿色选中态；当前值同时写进 `title` 与 `aria-label`。 |
| 数字/英文不算汉字 | 「金松果 +10000」「快进24小时」可以保留，但汉字部分仍不超过 4 个。 |
| 动态内容不硬改 | 道具名、玩家名、存档文件名属于内容，不是动作标签；可以长，但要用省略号截断 + `title` 展示全文。 |

## 2. 推荐用词

- 确认类：`确定`、`取消`、`返回`、`关闭`、`继续`、`稍后`。
- 存档类：`导入`、`导出`、`存档列表`、`粘贴`、`选文件`、`覆盖`、`载入`、`写入`。
- 战斗/成长类：`挑战`、`开始`、`查看`、`购买`、`出售`、`融合`、`升级`、`领取`、`装备`、`卸下`。
- 不要用：「点击这里」「请选择…」「确定要…吗」这类把说明塞进按钮的写法。

## 3. 布局约束

- 弹窗按钮区 `.modal-buttons` 允许换行；按钮 `min-width` 不再硬撑 200px，短标签优先一行。
- 系统页 4×2 网格（8 颗：存档导出 / 存档导入 / 修改昵称 / 跳过按钮 + 分辨率 / 全面屏 / 状态栏 / 调试面板）里，动作标签和状态徽章分开：`.btn-badge` 只放数字/短状态（开/关/自动/隐藏/显示）。
- 存档列表每行的「载入」固定 2 字；文件名放在副标题并用 `title` 展示全文。
- 验收视口：1170×690 设计尺寸 + iPhone 横屏（约 844×390）都必须不重叠、不越界。

## 4. 存档导入/导出（本次已按规范修改）

| 位置 | 旧文案 | 新文案 |
|---|---|---|
| 系统页 | 导出存档 / 导入存档 / 更改昵称 | **存档导出 / 存档导入 / 修改昵称**（用户 2026-10 指定保留完整四字） |
| 存档位置 | 立即写入存档文件 / 载入存档文件 / 从存档列表导入 | **写入存档 / 载入存档 / 存档列表**（用户 2026-10 指定保留完整四字，不缩写） |
| 导入入口 | 选择文件（文件 App）… / 粘贴存档文本… | 选文件 / 存档列表 / 粘贴 |
| 导出完成 | 分享到其它 App / 复制存档文本 / 知道了 | 分享 / 复制 / 确定 |
| 粘贴弹窗 | 从剪贴板粘贴 / 粘贴存档文本… | 粘贴 / 导入 / 取消 |
| 载入弹窗 | 用存档文件覆盖 / 选择本地文件… | 覆盖 / 选文件 |

> 例外（用户 2026-10）：系统 →「存档位置」的三颗键**固定用完整标签**
> 「写入存档 / 载入存档 / 存档列表」。`.sync-actions` 本身是 `flex-wrap`，窄屏会换行；
> 其余动作按钮仍按 2~3 字优先、最多 4 字的规则。

## 5. 新按钮怎么加

1. 先写动作本身，2~3 个汉字；细节写进弹窗正文、`title`、`aria-label`。
2. 需要显示数量/等级/价格时，用按钮内的小徽章（`<span class="btn-badge">`）或按钮下方的说明，不要写进标签。
3. 跑 `node tools/test-button-labels.cjs`；CI 会枚举 `tools/test-*.cjs`，新增违规会直接失败。
4. 视觉上再按第 3 节的视口各看一次，避免短标签在窄屏被固定宽度挤出去。

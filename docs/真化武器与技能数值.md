## 1. 真化机制（升级线 / 概率 / 费用 / 上限）

| 项目 | 规则 | 代码位置 |
|---|---|---|

| 成功率（每一档都是「从该级升下一级」） | Lv10→11 **100%**、11→12 **8%**、12→13 **5%**、13→14 **4%**、14→15 **3%** | `upgradeMap` 第 10~14 行 |
| 失败保底 | **真化不吃保底**（失败不 +5%，概率就是上表定值） | `state.js upgradeInfo()` 的 `fails = isTrue ? 0 : …` |
| 费用 | 真化第 N 次/天 = **10N 金松果**（10/20/30…），24:00 清零；普通升级固定 40 金松果 | `state.js trueUpgradeCost()` |
| 卷轴 | 每档都是 **25 张**（武器卷轴 id22 / 技能卷轴 id21）；普通升级的卷轴需求见原表 | `upgradeMap.book` |
| 角色等级门槛 | 真1 需 30 级、真2 35、真3 40、真4 45、真5 50 | `upgradeMap.levelLimit` |
| 调试开关 | 「升级必定成功」「升级无需消耗」对真化同样生效；`12 小时一天` 会让每日次数提前刷新 | `js/debug.js` |

## 4. 平衡性调整：建议先看的 9 个点

按「影响面 × 是否有背书」排序，前 3 个我建议优先定夺：

1. **真武器特效「双重计数」**（无背书，最可能是笔误）。
   `sim.js` 里 7 把真武器的特效写作 `weaponEffect(w, base, per, perTrue) + trueW(w, key)`：
   `perTrue` 已按真级累加，`trueW` 又把同一份 `remark1` 平加了一次。
   于是真5 实际是「字典值 → 每真级 +N，再 +N」：
   西瓜刀 58%（字典读起来像 33%）、板砖 55%、沉默之斧 **70%**、忍者镖 58%、激光剑 56%。
   *三种改法*：(a) 认为 `remark1` 就是真5 的总量 → 去掉 `perTrue`，只留 `trueW`；
   (b) 认为应当逐真级递增 → 去掉 `trueW`，保留 `perTrue`；(c) 维持现状，只改数值。
2. **暴击真5 的 4 倍几率 = 50%**（`src:'平衡'`），而 `攻略.md` 写的是 **20%**。
   4 倍暴击的期望倍率从 1.4× 拉到 2.5×（相对 2 倍暴击），是最容易失控的一条。
3. **通灵召唤 +18**（`用户提供`，无文件背书）：攻略反而建议 40 级后弃用。
   它的伤害跟「对手当前生命」挂钩（越打越弱），后期打高血 boss 尚可、打 PvP 残血目标几乎无效。
4. **皮糙肉厚真5**：19% 平减 + 反暴击 ×0.5 两个乘区叠在一起，攻略称「神技」——如果要削，
   建议先动 `antiCrit`（50% → 30/35%）而不是平减。
5. **绝对防御真5 反弹 96%**：全项目唯一没有 clamp 的减伤/反弹比例（龟甲术/皮糙肉厚都夹到 80%）。
   建议统一 `clamp(…, 0, 80)`，或明确「绝对防御可以超过 80%」。
   另外**投掷类攻击根本不触发绝对防御**（`需求140`，不挡也不反弹），所以这个 96% 只对
   近战 / 徒手 / 技能生效 —— 复算时要分开算；投掷也不需要靠"打它几次"来降它的权。
6. **龟甲术真5 二次起必触发**：`20 + trueVal(7)×100 = 120`（>100）。想让真5 是「100% 必挡」就
   保持不变；想留一点翻车空间就把 `trueVal(7)` 从加法改成「补到 85~95%」。
7. **被动基数与字典不符**：风驰电掣真5 `+16`（字典 15）、身强体壮真5 `+117`（字典 120）——
   `passiveBonus()` 里多了 `+2` / `+5` 的基数。若追求「与原版一致」可改为纯线性。
8. **真1~真4 全是线性插值**，没有史料。若你希望「真3 是质变点」（攻略多次提到真3），
   可以把 `trueSkillValue` 改成非线性（例如端点前压、真4→真5 陡增）。
9. **方天画戟真5 323~333 + 逐级 +12**：全武器最高面板，代价只是「第一回合准备」；
   在 50 级以后力量乘区下很容易一边倒，是武器侧最值得复算的一条。
   **真化后无视装死**（`需求138`，口径同橡皮擦 / 吸铁大法）——这条是 2026-10 用户口径新增，
   所以它现在是「面板最高 + 无视装死 + 只需让出一回合」，复算平衡时要把它算进去。
